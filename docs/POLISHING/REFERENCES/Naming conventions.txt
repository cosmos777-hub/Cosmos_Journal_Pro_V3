# Purpose

Ce document définit les conventions officielles de nommage utilisées dans Cosmos Journal Pro V3.

Ses objectifs sont :

- améliorer la lisibilité du code ;
- garantir la cohérence entre les modules ;
- faciliter le travail collaboratif entre développeurs et IA ;
- limiter la dette technique.

Ces conventions sont obligatoires pour tous les nouveaux développements.

---

# General Principles

Les noms doivent toujours être :

- explicites ;
- prévisibles ;
- cohérents ;
- orientés métier.

Éviter :

- les abréviations inutiles ;
- les noms génériques (`data`, `value`, `temp`, `obj`, `item`) ;
- les suffixes numérotés (`button2`, `panel3`, etc.).

# Naming Philosophy

Un nom doit permettre de comprendre son rôle sans lire son implémentation.

Si une variable, une fonction ou un composant nécessite une explication pour être compris, son nom doit être revu.

Le code doit être auto-documenté autant que possible.
